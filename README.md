# Golden Sax — Soportes para saxofón

Página web estática de Golden Sax: soportes para saxofón de acero y latón.

## Archivos

- `index.html`: contenido de la página.
- `style.css`: diseño y estilos.

## Ver la página

Abre `index.html` en tu navegador, o publícala con GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `(root)`).
